# 安装与快速开始

## 选择加载器

### Fabric

准备以下文件：

1. Minecraft `26.2`。
2. Fabric Loader `0.19.3` 或更高版本。
3. 与 Minecraft 26.2 匹配的 Fabric API；项目当前使用 `0.152.1+26.2` 构建和验证。
4. `one_enough_creative_tab-fabric-26.2-26.2.0.0.jar`。

将 Fabric API 和本 Mod 的 JAR 放入实例的 `mods` 目录。

### NeoForge

准备以下文件：

1. Minecraft `26.2`。
2. NeoForge `26.2.0.1-beta` 或更高版本。
3. `one_enough_creative_tab-neoforge-26.2-26.2.0.0.jar`。

将本 Mod 的 JAR 放入实例的 `mods` 目录。

> 不要同时安装 Fabric 和 NeoForge 版本。

## 单人游戏与多人游戏

- 单人游戏：安装在客户端即可，集成服务端会负责数据包生成和保存。
- 多人游戏：客户端和服务端必须使用相同加载器并安装本 Mod。Fabric 服务端还需要 Fabric API。
- 可视化编辑是服务端权威操作。只有具有“游戏管理员命令”权限的玩家才能进入编辑模式，保存时服务端会再次检查权限。

## 第一次进入世界

服务端启动后会：

1. 收集当前原版和已注册 Mod 的创造标签及最终物品内容。
2. 在 `<world>/datapacks/one_enough_creative_tab_generated_default/` 生成默认数据包。
3. 将该数据包固定在所有普通数据包下面。
4. 在内容变化时执行一次资源重载，并把解析结果同步给客户端。

首次生成时可能比后续启动多一次数据包重载。不要手工编辑该目录，下一次服务端启动会按当前原版与 Mod 状态重新生成它。

## 进入编辑模式

1. 进入创造模式并按 `E` 打开创造物品栏。
2. 长按任意标签、分类标签中的物品，或创造物品栏边框空白区域约 `500 ms`。
3. 标签或物品长按会直接打开“修改/删除”菜单；长按空白边框会直接进入主编辑界面。

如果长按没有反应，先确认自己拥有游戏管理员命令权限，再查看[故障排查](https://github.com/kltyton/OneEnoughCreativeTab/wiki/故障排查)。完整操作说明见[可视化编辑器](https://github.com/kltyton/OneEnoughCreativeTab/wiki/可视化编辑器)。

## 配置文件

当前版本没有独立配置文件。标签内容、布局和覆盖关系全部通过世界数据包及可视化编辑器管理。
