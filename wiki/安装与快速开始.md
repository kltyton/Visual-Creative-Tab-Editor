# 安装与快速开始

## 选择加载器

### Fabric

准备以下文件：

1. Minecraft `1.21.1`。
2. Fabric Loader `0.16.9` 或更高版本。
3. 与 Minecraft 1.21.1 匹配的 Fabric API；项目依赖配置为 `0.109.0+1.21.1`。
4. `visual_creative_tab_editor-fabric-1.21.1-2.1.0.jar`。

将 Fabric API 和本 Mod 的 JAR 放入实例的 `mods` 目录。

### NeoForge

准备以下文件：

1. Minecraft `1.21.1`。
2. NeoForge `21.1.80` 或更高版本。
3. `visual_creative_tab_editor-neoforge-1.21.1-2.1.0.jar`。

将本 Mod 的 JAR 放入实例的 `mods` 目录。

### Forge

准备以下文件：

1. Minecraft `1.21.1`。
2. Forge `52.0.28` 或更高版本。
3. `visual_creative_tab_editor-forge-1.21.1-2.1.0.jar`。

将本 Mod 的 JAR 放入实例的 `mods` 目录。

> Fabric、NeoForge 和 Forge 构建只能选择一个，不要同时安装。

## 单人游戏与多人游戏

- 单人游戏：安装在客户端即可，集成服务端会负责数据包生成和保存。
- 多人游戏：仅客户端安装时按服务器地址保存本地布局；双端安装相同版本时使用服务端共享布局。Fabric 服务端安装本 Mod 时需要 Fabric API。
- 双端模式使用服务端权限校验，保存时再次检查游戏管理员命令权限。仅客户端模式只调整本机创造物品栏，不修改服务器数据。

## 第一次进入世界

服务端启动后会：

1. 收集当前原版和已注册 Mod 的创造标签及最终物品内容。
2. 在 `<world>/datapacks/visual_creative_tab_editor_generated_default/` 生成默认数据包。
3. 将该数据包固定在所有普通数据包下面。
4. 在内容变化时执行一次资源重载，并把解析结果同步给客户端。

首次生成时可能比后续启动多一次数据包重载。不要手工编辑该目录，下一次服务端启动会按当前原版与 Mod 状态重新生成它。

## 进入编辑模式

1. 进入创造模式并按 `E` 打开创造物品栏。
2. 长按任意标签、分类标签中的物品，或创造物品栏边框空白区域约 `500 ms`。
3. 标签或物品长按会直接打开“修改/删除”菜单；长按空白边框会直接进入主编辑界面。

如果长按没有反应，先确认自己拥有游戏管理员命令权限，再查看[故障排查](https://github.com/kltyton/Visual-Creative-Tab-Editor/wiki/故障排查)。完整操作说明见[可视化编辑器](https://github.com/kltyton/Visual-Creative-Tab-Editor/wiki/可视化编辑器)。

## 配置文件

世界内保存仍使用数据包。“跨档保存”把当前草稿写入 `config/visual_creative_tab_editor/global.json`，作为尚无玩家覆盖的新世界的初始模板；已有世界的独立编辑优先。仅客户端多人模式使用同目录下 `servers/<服务器地址摘要>.json`，未保存过该服务器时使用全局模板。
