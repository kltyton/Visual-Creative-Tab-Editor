# 2.3.1

## English

- Fix compatibility with Flavor Immersed Daily's expandable creative-tab sections. Native catalogs retain the full item contents independently of the current collapsed layout, while the mod's banner rendering and click handling remain active.
- Preserve the original backing item collections when rebuilding native catalogs. Generated default catalogs refresh on world startup; player overrides and global editing preferences are retained.
- Update the build infrastructure to KltytonTemple 1.5.3, including Forge pack metadata, metadata parsing, UTF-8 text handling and project creation interfaces. Existing Minecraft, Loader, Java, Gradle and build-plugin versions are preserved.

- 重建原生目录时保留原始底层物品集合。生成的默认目录在进入世界时更新，玩家覆盖数据与全局编辑偏好保留。
